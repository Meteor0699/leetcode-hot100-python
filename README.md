## 这套教程解决什么问题

LeetCode「热题 100」是大厂面试最高频的 100 道算法题。但很多人打开第一题就卡住了——不是不会算法，是**不知道怎么把想法变成代码**，或者**代码报错看不懂**。

网上大部分教程解决不了这个问题，常见三种毛病：

| 常见做法 | 问题 |
|---|---|
| 「假设你已经会编程」，直接从「数组的两种遍历方式」开始 | 零基础的人第一章就掉队 |
| 算法部分写「详见 XX 讲义」「前面讲过了」 | 读者根本没有那份资料，最核心的内容是空的 |
| 只给答案代码，不讲「怎么想到的」 | 看得懂但写不出，换个题就废 |

这套教程的做法不一样：

- **自包含**：12 个文件就是全部，没有「请参考某某章节」的外链。算法本身也从零讲。
- **先讲套路，再讲题**：每册开头先用大白话讲清「这类题到底在干嘛、套路为什么成立」，再逐题展开。目标是**换个没见过的同类题也能做出来**，而不只是背下这 100 题。
- **每题都讲「怎么想」**：从笨办法讲到巧办法，重点是中间那一跳是怎么发生的，不是「答案是这个」。
- **写给真的会卡住的人**：每章有「动手练」，每题有「易错点」，最后有「闭卷自测」。

## 适合谁 / 不适合谁

**适合：**

- 完全没学过编程，或者大学学过 C / C++ 但「写不出代码」
- 会一点 Python，但一到算法题就懵
- 刷过题但只会背题号对应的解法，换个题就不会
- 想系统补一遍「算法思维」，但不知道从哪下手

**不适合：**

- 已经能独立刷中等题，想找进阶技巧（去 LeetCode 官方题解或《算法导论》）
- 想学 Web 开发、数据分析、机器学习（这不是这类教程）
- 想要视频课或交互式练习（这是读文字的）

## 快速开始

### 1. 拿到文件

```bash
git clone https://github.com/Meteor0699/leetcode-hot100-python.git
```

也可以直接在线读，在 GitHub 上点开 [`START-HERE.md`](START-HERE.md) 就行。

> **只想挨个看题目和答案？** 直接双击打开 [`leetcode-100.html`](leetcode-100.html)——单文件、离线可用、不用装任何东西。100 道题按题号排列，点开就能看 **LeetCode 官方中文题面**（含约束与示例，标注来源并附官网直达链接）、思路、复杂度和可复制的 Python 答案；支持搜索、按难度/专题筛选、标记「已看」（进度存在本机浏览器）。网页版：https://meteor0699.github.io/leetcode-hot100-python/

### 2. 打开 `START-HERE.md`

**这是入口**，里面有完整路线图、12 周计划和进度表。别从 `L01` 直接开始——先看这页，你会知道每一章该花多久、什么时候该停下来。

### 3. 装 Python

第 1 章第一节就从下载开始教，跟着做就行。没有 Python 也能先看前两章。

### 4. 今天就做两件事

把 `print("你好")` 跑起来，然后**故意**写错一次缩进，看看报错长什么样。

> 会看报错，比会写代码更早救命。

| 周 | 学什么 | 刷题 |

| W1 | L01 全章 + 动手练 | 0 |

动态规划（L09 后半）是最难的一章，允许自己多花一周，别硬赶。

## 怎么用这个仓库

### 在线读

GitHub 上直接点开任意 `.md` 文件即可，表格、代码块、图片都能正常渲染。

